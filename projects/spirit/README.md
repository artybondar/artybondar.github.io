# Духовность без иллюзий — лендинг

Статический лендинг: `index.html`, `style.css`, `script.js`, `robots.txt`, `sitemap.xml`, `images/`. Без зависимостей и сборки.

## Перед публикацией — 3 вещи, которые надо заменить

1. **Домен.** Сейчас во всех мета-тегах (`index.html`), `robots.txt` и `sitemap.xml` стоит заглушка `https://duhovnostbezilluzii.github.io/`. Замени на свой реальный адрес после деплоя (обычным find/replace по всем трём файлам).
2. **Яндекс.Метрика.** Зарегистрируй счётчик на [metrika.yandex.ru](https://metrika.yandex.ru), получишь числовой ID — замени им `00000000` в двух местах в `index.html` (в скрипте счётчика и в `<noscript>` строкой ниже).
3. **OG-картинка.** Уже лежит в `images/og-image.png` (1200×630) — так будет выглядеть превью при шеринге в VK/Telegram. Если поменяешь текст на лендинге, картинку стоит перерисовать под него (исходник — `images/og-source.svg`).

## SEO, что уже сделано

- `<title>` и `<meta description>` переписаны под поисковые запросы аудитории (не «духовный лендинг», а конкретные фразы вроде «практики для женщин без эзотерики»).
- Open Graph + Twitter Card — корректные превью при шеринге в соцсети.
- JSON-LD (schema.org/Organization) со ссылками на VK и Instagram — помогает поисковикам и соцсетям понимать, что это официальный сайт бренда.
- `robots.txt` и `sitemap.xml` — чтобы поисковики корректно индексировали единственную страницу.

## Деплой на GitHub Pages

1. Создай репозиторий и залей туда все файлы.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/root`.
3. Сохрани — через минуту страница будет доступна по адресу
   `https://<username>.github.io/<repo>/`.

## Локальный просмотр

Просто открой `index.html` в браузере, либо из папки:

```bash
python3 -m http.server 8000
```

и зайди на `http://localhost:8000`.
